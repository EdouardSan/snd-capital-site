# Product

## Register

brand

## Users

Deux audiences : (1) l'équipe de validation Apple Developer, qui vérifie que la société existe, décrit son activité et est joignable ; (2) de futurs clients ou partenaires qui cherchent une présence sobre et crédible.

## Product Purpose

Site vitrine one-page de SND Capital, studio français de développement d'applications et de logiciels. Objectif : satisfaire les exigences du compte Apple Developer (nom de la société, description de l'activité, coordonnées de contact) avec un site propre et professionnel. Hébergé sur GitHub Pages, domaine snd-capital.fr.

## Brand Personality

Sobre, précis, fiable. Un cabinet d'ingénierie discret : confiance par la retenue, pas par le spectacle.

## Anti-references

Pas de landing page SaaS générique (grilles de cartes identiques, gradient text, hero-metric). Pas de maximalisme : le site doit rester très simple, une seule page.

## Design Principles

- La simplicité est le livrable : une page, trois sections, zéro friction.
- La couleur de marque (teal profond, oklch 0.40 0.088 170) porte l'identité ; le fond reste blanc pur.
- Typographie unique (Archivo) avec contraste de graisses plutôt que multiplication de familles.
- Contenu en français, coordonnées visibles sans chercher.

## Accessibility & Inclusion

Contrastes ≥ 4.5:1 sur tout le texte courant. `prefers-reduced-motion` respecté. HTML sémantique, site statique sans JavaScript.
